# 产品价格导入功能

## 功能说明
在 `/admin/products` 页面新增了"导入价格"功能，可以通过Excel批量更新物料的销售价和采购价。

## 实现内容

### 1. 文件结构
```
app/
├── Admin/
│   ├── Actions/Grid/
│   │   └── ImportProductPrice.php          # 价格导入按钮工具
│   ├── Controllers/
│   │   └── ProductPriceImportController.php # 价格导入控制器
│   └── Forms/
│       └── ProductPriceImportForm.php       # 价格导入表单
└── Services/
    └── ProductPriceImportService.php        # 价格导入服务
```

### 2. 路由设置
在 `app/Admin/routes.php` 中添加了以下路由：
- `GET /admin/products/price/import` - 价格导入页面
- `GET /admin/products/price/import/template` - 下载导入模板

### 3. 使用方法

#### 步骤1：访问导入页面
在 `/admin/products` 页面点击"导入价格"按钮（绿色按钮，旁边是原有的"导入物料"按钮）

#### 步骤2：下载模板
在导入页面点击"下载导入模板"链接，获取Excel模板文件

#### 步骤3：填写数据
模板包含3列：
- **物料编号**（必填）：需要更新的物料编号
- **销售价**（可选）：新的销售价格
- **采购价**（可选）：新的采购价格

示例：
```
物料编号    | 销售价  | 采购价
ITEM001    | 100.00 | 80.00
ITEM002    | 200.00 | 150.00
```

#### 步骤4：上传文件
选择填写好的Excel文件，点击提交完成导入

### 4. 功能特点

✅ **灵活更新**：销售价和采购价可以只填其中一个，未填写的字段不会被更新
✅ **批量操作**：支持一次性更新多个物料的价格
✅ **数据验证**：
   - 物料编号必填且必须存在
   - 价格必须为数字且大于等于0
   - 物料编号不存在的行会被跳过

✅ **事务保护**：使用数据库事务，确保数据一致性
✅ **详细反馈**：导入完成后显示更新数量、跳过数量和错误信息
✅ **日志记录**：每次价格更新都会记录到系统日志

### 5技术实现

- **Excel解析**：使用 `Dcat\EasyExcel\Excel` 解析Excel文件
- **数据库操作**：使用 Eloquent Model 更新，支持事务回滚
- **字段映射**：
  - `sale_price` - 销售价
  - `purchase_price` - 采购价

### 6. 注意事项

⚠️ 导入的Excel文件首行必须包含表头：物料编号、销售价、采购价
⚠️ 物料编号必须与系统中的 `item_no` 字段完全匹配
⚠️ 单个文件建议不超过 2MB
⚠️ 支持的文件格式：xlsx, xls, csv
